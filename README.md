## 📋 Описание

**Code Cleaner** — это приложение с графическим интерфейсом на PyQt6, предназначенное для автоматической очистки кода от комментариев, пустых строк и других ненужных элементов. Приложение поддерживает множество языков программирования и предоставляет расширенные возможности для работы с проектами.

### ✨ Основные возможности

- 🎯 **Умная очистка комментариев** — автоматическое удаление комментариев с учетом синтаксиса языка
- 📊 **Статистика по проекту** — детальная аналитика кода (строки, функции, классы, размер файлов)
- 🔧 **Профили настроек** — сохранение и переключение между наборами настроек
- 📜 **История изменений** — отслеживание всех операций с возможностью отката
- 🚀 **Пакетная обработка** — одновременная обработка множества файлов
- ✅ **Проверка синтаксиса** — автоматическая валидация кода после очистки
- 💾 **Резервные копии** — автоматическое создание бэкапов перед изменениями
- 🎨 **Темный интерфейс** — современный и удобный UI

## 🚀 Установка

### Требования

- Python 3.8 или выше
- PyQt6 6.6.0 или выше

### Шаги установки

1. **Клонируйте репозиторий или скачайте файлы проекта**

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение:**
   ```bash
   python CodeCleaner.py
   ```

## 📖 Использование

### Быстрый старт

1. **Откройте проект**
   - Нажмите кнопку "📁 Открыть папку проекта"
   - Выберите папку с вашим проектом
   - Приложение автоматически определит языки программирования

2. **Выберите файлы**
   - Используйте чекбоксы в дереве файлов для выбора
   - Можно выбрать всю папку — все файлы внутри автоматически выберутся
   - Используйте кнопки "Выбрать все" / "Снять выделение" для массового выбора

3. **Настройте опции очистки**
   - Перейдите на вкладку "⚙️ Настройки"
   - Выберите нужные опции:
     - ✅ Удалить комментарии
     - ✅ Удалить пустые строки
     - ✅ Проверить код после выполнения
     - ✅ Создать requirements.txt (Python)
     - ✅ Дополнительные функции

4. **Обработайте файлы**
   - Нажмите "🚀 Обработать выбранные файлы"
   - Следите за прогрессом в прогресс-баре
   - Просматривайте результаты в логе операций

## 📝 Примеры использования

### Пример 1: Очистка Python проекта

1. Откройте папку с Python проектом
2. Выберите все `.py` файлы
3. Включите опции:
   - Удалить комментарии
   - Удалить пустые строки
   - Проверить код после выполнения
   - Создать requirements.txt
4. Нажмите "Обработать"

### Пример 2: Работа с профилями

1. Настройте нужные опции очистки
2. Перейдите на вкладку "Профили"
3. Нажмите "Сохранить текущие настройки"
4. Введите имя профиля (например, "Python Clean")
5. При следующем использовании просто выберите профиль из списка

### Пример 3: Восстановление из истории

1. Перейдите на вкладку "История"
2. Найдите нужную операцию в списке
3. Дважды кликните или нажмите "Восстановить"
4. Подтвердите восстановление
